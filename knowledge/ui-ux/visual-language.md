# Visual Language

A strong interface has a small number of coherent visual decisions.

## Hierarchy

Hierarchy should answer, in order:

1. Where am I?
2. What matters most?
3. What can I do?
4. What changed?
5. What is secondary?

Use:

```text
size
weight
spacing
position
contrast
grouping
surface
motion
```

Do not use all channels at full strength simultaneously.

## Composition

Choose a composition because it supports content.

### Symmetric

Useful for:

- trust
- calm
- straightforward comparison
- centered narratives
- forms with one dominant task

Risk: generic presentation when every section is centered and equally weighted.

### Asymmetric

Useful for:

- editorial rhythm
- brand expression
- priority contrast
- media-led presentation

Risk: ambiguous reading order or responsive collapse.

### Dense grid

Useful for:

- dashboards
- monitoring
- inventory
- data-heavy tools

Risk: every metric becoming equal.

### Open/spacious

Useful for:

- marketing
- premium presentation
- editorial
- portfolios

Risk: low information efficiency or giant empty sections.

## Spacing

Spacing is a grouping system, not decoration.

Closer means more related.

Larger gaps should correspond to stronger semantic boundaries.

Avoid random spacing values that make hierarchy impossible to learn.

## Shape

Corner radius communicates character and grouping.

Use fewer radius levels.

Do not make every surface a rounded rectangle.

Pills are strongest for compact states, filters, segmented choices, or small actions where the shape has a reason.

## Borders and elevation

Use borders for:

- separation
- structure
- states
- boundaries

Use elevation for:

- layering
- floating controls
- temporary surfaces
- spatial hierarchy

If every element is elevated, elevation conveys nothing.

## Imagery

Prefer imagery that contributes:

- proof
- product understanding
- atmosphere tied to brand
- narrative
- information

Avoid generic stock imagery added only to fill space.

## Signature

A design usually needs one or two memorable ideas, not ten.

Examples of signature categories:

```text
typographic
layout
illustration
interaction
material/texture
data visualization
navigation
brand motif
```

The signature should be recognizable without making every component unusual.
