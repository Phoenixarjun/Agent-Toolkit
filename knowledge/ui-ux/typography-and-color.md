# Typography and Color

## Typography

Typography is an information system before it is a style choice.

Define semantic roles first.

Typical roles:

```text
display
title
heading
body
label
caption
code/data
```

The hierarchy can vary through:

```text
font family
size
weight
line height
letter spacing
measure
case
color
```

Avoid overusing uppercase for long labels or body content.

Avoid very long centered paragraphs.

Keep long-form line measure comfortable and responsive.

Use tabular figures when changing numeric values need stable alignment.

### Font selection

Judge fonts on:

- legibility at required sizes
- character fit
- weights and styles needed
- language coverage
- loading/performance
- platform expectations
- brand ownership/licensing
- readability under density

Do not choose a distinctive display face for body copy merely to be unusual.

Do not reject a familiar UI font when familiarity is an advantage.

## Color

Start from semantic roles, not a gallery of palettes.

A compact system may include:

```text
canvas
surface
surface-raised
text
text-muted
border
brand
accent
focus
success
warning
danger
```

Add tokens only when a real semantic need exists.

### Contrast

WCAG 2.2 AA commonly requires:

```text
normal text: 4.5:1
large text: 3:1
non-text UI/meaningful graphics: 3:1 where the criterion applies
```

Verify rather than estimating by eye.

### Color meaning

Never communicate a status only through hue.

Combine color with at least one of:

```text
text
icon
shape
pattern
position
label
```

### Dark mode

Dark mode is a separate contrast and hierarchy problem, not color inversion.

Re-evaluate:

- text contrast
- borders
- elevated surfaces
- brand saturation
- semantic colors
- images and illustrations
- focus indicators

### Palette character

A brand can feel distinctive through proportion and relationships, not necessarily many colors.

A restrained neutral system with one precise accent can be more recognizable than a rainbow palette.

Avoid automatically reaching for blue/purple gradients for technology products.
