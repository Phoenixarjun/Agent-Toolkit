# Career quality rubrics (baseline v1)

Use common anchors from `delegation-and-review.md`. Material truth, authorization, confidentiality and actual eligibility remain non-compensable gates. Candidate preferences and task-specific thresholds are set before critique. Do not confuse these judgments with employer decisions or external metrics.

| Domain | Applicable dimensions and evidence of strong performance |
|---|---|
| Career plan | Target clarity; demonstrated baseline; durable pillar fit; role relevance; capacity/dependency feasibility; contingency; milestones with observable outcomes; adaptive review; no unnecessary work. |
| LinkedIn profile | Target positioning in headline; About communicates actual scope and direction; experience/skills defensible; projects and Featured support claims; human readability; consistent narrative and platform limits; no fake discoverability promises. |
| GitHub profile | Discoverable relevant evidence; README communicates purpose, setup and limitations; actual repo contents support scope; tests/docs/architecture signals where present; appropriate pinned projects; no invented activity or stars. |
| Other presence | Platform-specific audience/task; credible evidence; identity consistency; privacy; accessibility and current constraints. |
| Topic selection | Technical significance; target-role relevance; evidence depth; opportunity for authentic learning; audience usefulness; timeliness without hype. |
| LinkedIn content | Grounded insight; specific hook; coherent narrative; authentic voice; concrete takeaway; accurate attribution; no invented experiments or engagement promises. |
| Technical blog | Clear technical question; source accuracy; causal explanation; reproducible or clearly hypothetical examples; counterexamples and tradeoffs; audience fit; logical structure; no fabricated measurements. |
| Projects | Problem clarity; target relevance; engineering depth; observable implementation; test/reproducibility evidence; documentation; ownership and limitations; effort/value. |
| Resume/application | Fact integrity; role relevance; defensible scope and metrics; key requirements mapping; concise hierarchy; readable extraction if exported; user constraints; no fictional ATS score. |
| Opportunity | Source liveness; requirement evidence; hard constraints; candidate-side value; uncertainty; clear decision and next action. |
| Company | Correct employer identity; source quality/freshness; product/business reality; role/team specificity; conflicting evidence and uncertainties; actionable questions. |
| Interview | Observed answer accuracy; depth; reasoning; communication; role-specific competency and evidence; fair follow-ups; no fabricated employer rubric or readiness guarantee. |
| Offer | Verified terms; correct arithmetic; cash vs equity distinctions; risk and constraints; candidate goals; negotiation evidence; unanswered questions. |

For interview competency use observed evidence, not perceived confidence: 0 materially wrong; 1 incomplete and needs substantial prompting; 2 adequate with gaps; 3 clear, accurate and defensible; 4 explains tradeoffs, failure modes and evidence beyond requirement. NOT_ASSESSED for unasked topics. Give concrete next drill and what would demonstrate improvement. Do not downgrade a person because of protected characteristics, unrelated social presence or accent. An adversarial critic must challenge claims and assumptions, not manufacture conflict. Stop when criteria pass.
