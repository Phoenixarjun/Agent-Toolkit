# Content Intelligence: Research

Load content-and-platforms, workspace, delegation and rubrics. Identify objective (learn, share, career credibility, audience growth), target role/audience, time, author mode, publication history and existing research. For explicit topic skip discovery unless comparison requested. Reuse a fresh topic dossier where applicable.

1. Assign `career-content-manager` to propose source scopes/selection criteria. Use existing `research` workflow, with 2–3 complementary scout contexts for substantial discovery if supported. Primary source families plus community signals; search beyond shortlist when needed. Scope date/window and domain. Collect dated source IDs, claims, original evidence, practical impact, contradictory evidence and limitations. No arbitrary link quota.
2. Manager returns shortlist (1–3) and distinction foundational/breakthrough/practical/trending. Dispatch `career-critic` as topic skeptic with independent criteria. Reconcile in lead; two challenge rounds max, no peer chatter. Choose one topic or let candidate choose when material preference. Explain why popular alternatives were rejected. If weak evidence, defer rather than manufacture a breakthrough.
3. Deep research selected topic via existing research; independent source verifier checks support and counterevidence. Separate factual findings, hypotheses, proposed experiments and actual candidate insights. For original personal angle ask for experience/experiment if needed. Store or return reusable dossier (topic ID, question, sources, findings, limitations, experiments, user insights, date/freshness, approved angle). Do not draft when research-only. If user requested publication direction, pass dossier to named downstream workflow without recursion; no autonomous publish.

Output: ranked topic shortlist/selected topic, tradeoffs, source ledger, verified research synthesis, technical learning/experiment suggestions if useful, potential channels, uncertainty and next action. Research absence or isolation degradation is explicit.
