# LinkedIn Content

Load content-and-platforms, workspace, delegation and rubric. This is content production, not profile optimization. Obtain audience, goal, user voice, topic/dossier or source material, desired authoring mode and constraints. For discovery/research invoke `career-content-research` directly if no adequate dossier; when existing verified topic reused, check freshness and only investigate missing claims. No repeated research for same fact.

Content manager proposes angle and takeaway. Candidate may prefer research-only or outline; honor it and stop at requested boundary. For drafting, `career-content-writer` uses actual evidence and user insights, `career-content-editor` improves voice/presentation, fresh `career-evidence-verifier` checks personal and technical claims; independent external verification through `research` for material source claims. `career-critic` applies channel rubric and audience lens; no forced clickbait or engagement tricks. Targeted revision max two, verify changed claims after final edit. For unsupported personal experiment use clearly hypothetical or external attribution, or ask user. Reuse original research for blog adaptation without duplicating identical copy.

Return exact post draft (or requested outline), optional alternate angle only if helpful, source notes, claim/voice caveats, review disposition and user publication checklist. No posting, replying, automated comment generation at scale or scheduling. Analyze only supplied/authorized analytics if asked; report observed metrics and not inferred algorithm guarantees.

For an approved recurring content occurrence, recover previous topics, existing draft and publication history before selecting a topic. Reuse or continue the existing occurrence when present; return a new version only when justified. Persist the actual draft/verification and user-confirmed publication separately; record the occurrence acceptance and hand off to coordinator for cadence advancement.
