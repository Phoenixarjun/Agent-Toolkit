# Blog / Long-form Content

Load content-and-platforms, workspace, delegation and rubric. Establish topic, reader, technical depth, user voice, intended platform (Medium or other), format and desired authoring mode. Reuse verified topic dossier or call `career-content-research` directly. Clarify whether user wants learning aid, outline, collaborative draft or full article. Do not assume technical domain if user is in another profession.

1. Manager proposes central question, thesis, audience, claims and outline. Separate source-backed insights from user experience; mark experiment opportunities. For collaborative writing ask outline approval before drafting and draft one agreed section per turn; full draft only when requested. In research-only stop at dossier/outline.
2. Writer instances can own separate approved sections with shared facts and narrative brief. For conceptual diagrams/code examples distinguish illustrative vs actually executed; do not fabricate benchmark results or personal experiments. Editor assembles coherent narrative, preserves voice, removes repetition, ensures source attribution. Independent verifier checks factual claims and calculations; use existing `research` for external support. Critic checks technical argument, counterexamples, practical value and reader fit; revision budget two, final reverify.
3. Deliver outline or article in requested scope, citations/links, diagram/experiment suggestions only when useful, exact metadata if requested, uncertainty, verification status and user publication checklist. Optional LinkedIn adaptation invokes `career-linkedin-content` with same dossier; no automatic cross-post. No publish or schedule.

For recurring content, reuse the existing dossier and incomplete article before proposing another; record draft and actual publication as separate events. Candidate approval of a draft is not publication. Record occurrence acceptance and hand off to coordinator.
