# Offer Intelligence

Load opportunity-and-hiring, workspace, delegation and rubric. Obtain actual terms, currency/period, candidate priorities, deadline, location and constraints. Request missing material terms only; avoid mandatory salary history. Use `career-offer-analyst` for normalized comparable scenario analysis, company investigator/research only if needed for unresolved risk or current market evidence. Independently check arithmetic and source assumptions using verifier for material claims and critic for decision tradeoffs. Separate guaranteed cash, contingent variable, vesting, liquidity, taxes/benefits and contract uncertainty; don't assert legal/tax outcome without appropriate professional verification. Compare options incl. retain current position/no offer if relevant. Prepare negotiation draft with truthful leverage and range if requested; user controls all communication and acceptance. Return terms table, calculations, tradeoffs, downside, unresolved questions, recommendation and next action. No offer accepted/declined or tracker state changed without candidate confirmation.
