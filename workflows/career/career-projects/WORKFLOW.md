# Project Intelligence

Load workspace, adaptive-planning, delegation and rubric. Recover target, time, evidence, existing commitments and authorized work samples. Ask whether evaluate, improve or suggest projects. Assign `career-project-evaluator` per distinct relevant project for substantial audit; reuse existing `code-explore` or `code-review` only for scoped technical inspection. Separate actual artifact evidence from claimed outcomes. Independently verify material claims. Rank by role relevance, distinctiveness, engineering/domain depth, effort, evidence and defense readiness. Do not force new projects when existing work suffices or user locked portfolio. Select small flagship set; propose no more than four new options by default, only when real gap. Include problem, differentiation, feasible scope, proof, acceptance and opportunity cost. Critic challenges value/feasibility; do not build project here. Output existing portfolio assessment, preserve/improve/defer, proposed options if justified, next steps and evidence checks. Candidate controls any changes.
